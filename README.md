# XNotForMe

Not only X/Twitter has [nuked](https://tapbots.com/tweetbot/) all 3rd party apps, they now force a For You timeline filled with ads, unrelated topics, trash content and doomscrolling designed to waste your time.

This is a quick and dirty tweak to regain your sanity and completely hide the For You tab in the X timeline. The only timeline you need is the chronological one, with posts only from people you follow.

## Features

- Completely removes the `For You` tab
- Always uses the chronological `Following` timeline
- Hides the now-unnecessary timeline selector bar
- Preserves the home timeline scroll position across launches

## Compatibility

The current version supports X v12.3 - pair it with [NeoFreeBird](https://github.com/theacrat/NeoFreeBird) for more customization options.
